When to use it

  • Your hotspot is blocked after using up your dataOnce you're throttled, laptops and tablets can't use your hotspot
  • Hotspot doesn't work on an MVNO planThe hotspot turns on, but connected devices get no internet
  • The old way was too complicatedNo more installing DunUnlocker and Shizuku and jumping between screens

How to use

  1. Turn on Developer optionsTap [Open About phone], then tap Build number 7 times in Software information.
  2. Turn on Wireless debuggingTap [Open Wireless debugging] and turn it on. If asked, tap Allow.
  3. Enter the 6-digit codeTap [Start code entry], open "Pair device with pairing code", then type the number into the notification at the top.
  4. ApplyThe app adds dun to your current APN and turns wireless debugging off. When you see "Applied", turn on your hotspot.

You only do this once. To apply again or restore, just turn on wireless debugging and tap the button.

FAQ

Does hotspot use still eat into my tethering/sharing allowance?

Probably not. Hotspot traffic goes out through the same APN as normal data instead of a tethering APN. It isn't guaranteed: if your carrier detects tethering another way, it may still count it or block it. It also uses your normal data instead, so it isn't free.

Which phones does it work on? Only Galaxy?

Any phone on Android 13 or later. It was built with Galaxy (One UI 7+) in mind because that's where the problem is common, but it uses standard Android features, so it works the same way on other brands. You need Wi-Fi during setup; Wi-Fi without internet works too.

Can I undo it?

Yes. Tap Restore original in the app to put the APN type and default APN back.

Do I need a PC or Shizuku?

No. The app connects to the phone's wireless debugging itself. You enter a 6-digit pairing code in a notification once.

Is it safe?

Yes. All source code is on GitHub, and there is no server, ads, or analytics, so it collects no personal data. The app does one thing: add dun to your APN. It turns wireless debugging off when done. See the Safety section on this page.

Getting around tethering limits may break your carrier's terms, and your line could be restricted. Use it at your own judgment.
