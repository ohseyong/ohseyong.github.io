공유데이터 제한 해제,
앱 하나로

공유데이터를 다 써서 핫스팟이 막혔을 때 쓰는 앱입니다. APN 유형에 dun을 추가해 핫스팟 트래픽이 기본 데이터로 나가도록 합니다. 모든 과정이 폰 안에서 끝나며 PC 연결이나 루팅은 필요 없습니다.

APK 받기 GitHub에서 보기

안드로이드 13 이상, 무료, Apache-2.0 오픈소스

이럴 때 씁니다

  • 무제한 요금제인데 노트북을 핫스팟에 연결하면 테더링 한도에 걸리는 경우
  • 통신사 앱에 공유데이터가 소진됐다고 표시되는 경우
  • 알뜰폰에서 핫스팟은 켜지지만 연결한 기기에서 인터넷이 안 되는 경우
  • 데이터를 다 써서 속도 제한이 걸린 상태에서도 핫스팟을 쓰려는 경우

사용 방법

순정 안드로이드 15 에뮬레이터 화면입니다. 갤럭시는 메뉴 모양이 조금 다르지만 순서는 같습니다. 파란 상자가 누를 위치입니다.

1개발자 옵션 켜기

2무선 디버깅 켜기

3코드 입력

4완료

페어링은 처음 한 번만 하면 됩니다. 이후 다시 적용하거나 되돌릴 때는 무선 디버깅만 켜고 버튼을 누르면 됩니다.

유심이 두 개인 경우

사용 중인 유심 모두에 dun을 추가하고, 각 유심에서 해당 APN을 기본으로 지정합니다. 데이터 유심을 바꿔도 다시 적용할 필요가 없습니다. 되돌리기도 유심별로 처리하므로 다른 유심 설정에는 영향이 없습니다.

변경된 APN 확인

설정 → 연결 → 모바일 네트워크 → 액세스 포인트 이름에서 선택된 APN이 DunDun이 변경한 APN입니다. APN 유형 끝에 dun이 붙어 있습니다.

기기에 따라 기존 APN에 dun만 추가되거나, 같은 이름의 APN이 하나 더 생깁니다. 이때는 유형에 dun이 있는 쪽이 변경된 APN입니다. 통신사가 넣어 둔 Tethering 등 별도 APN은 변경하지 않습니다. 유심별 APN 이름과 유형은 앱의 적용 완료 화면에서도 볼 수 있습니다.

그 밖의 기능

  • 앱 상단에 현재 적용 여부가 표시됩니다. 통신사 설정 변경 등으로 풀리면 바로 알 수 있습니다.
  • 새 버전은 GitHub에서 받아 자동으로 설치합니다. 설치 허용은 처음 한 번만 묻습니다.
  • 한국어, 영어, 일본어, 중국어, 스페인어 등 12개 언어를 지원합니다.

안전

  • 소스 코드는 GitHub에 모두 공개되어 있습니다.
  • 별도 서버, 광고, 분석 도구가 없습니다. 앱이 외부와 통신하는 경우는 GitHub에서 새 버전을 확인할 때뿐입니다.
  • 무선 디버깅은 APN 변경에만 쓰며, 작업이 끝나면 앱이 바로 끕니다.
  • 적용 후 개발자 옵션을 꺼도 변경된 APN은 유지됩니다.
  • '원래대로 되돌리기'로 처음 상태를 복구할 수 있습니다.
  • 업데이트는 같은 키로 서명된 파일만 설치합니다. 서명 인증서 SHA-256: 4B:4B:E3:6B:A7:5E:D7:EA:5D:86:2D:23:8D:FC:C0:7A:10:0E:57:5C:19:49:75:05:D1:12:55:F9:17:F0:C1:66

요청 권한

  • 인터넷GitHub 업데이트 확인과 다운로드, 폰 내부 무선 디버깅 연결
  • 네트워크와 와이파이 상태와이파이 연결 여부와 현재 적용 상태 확인
  • 와이파이 멀티캐스트폰 내부 무선 디버깅 주소 검색
  • 알림, 전체 화면 알림페어링 코드 입력 알림을 화면 위에 유지
  • 포그라운드 서비스코드 입력과 적용 중 앱 종료 방지
  • 앱 설치GitHub에서 받은 새 버전 설치(처음 한 번만 확인)
  • 절전 해제, 부팅 완료하루 한 번 업데이트 확인 예약

연락처, 위치, 사진과 파일, 전화, 카메라, 마이크 권한은 요청하지 않습니다. 무선 디버깅의 페어링된 기기 목록에 DunDun이 남으며, 다시 적용하거나 되돌릴 일이 없으면 삭제해도 됩니다.

자주 묻는 질문

테더링을 무제한으로 쓸 수 있나요?

아니요. 핫스팟이 공유데이터 대신 기본 데이터를 쓰게 됩니다. 기본 데이터를 다 쓰면 요금제의 제한 속도가 핫스팟에도 적용됩니다.

적용 후에는 공유데이터가 차감되지 않나요?

대부분 차감되지 않습니다. 통신사는 주로 APN으로 핫스팟 트래픽을 구분하는데, 적용 후에는 핫스팟도 일반 데이터와 같은 APN을 씁니다. 다른 방식으로 구분하는 통신사라면 그대로 차감되거나 차단될 수 있으니, 처음에는 조금 써 본 뒤 통신사 앱에서 차감 내역을 확인하시기 바랍니다.

NetShare와 무엇이 다른가요?

NetShare는 프록시 방식이라 노트북에 프록시를 설정해야 하고, 카카오톡 PC처럼 로그인되지 않는 프로그램도 있습니다. DunDun은 폰의 APN만 바꾸므로 기본 핫스팟을 그대로 쓰며, 노트북에서는 설정할 것이 없습니다.

갤럭시에서만 되나요?

안드로이드 13 이상이면 됩니다. One UI 7 이상 갤럭시에서 이 문제가 많이 보고되어 갤럭시를 기준으로 맞췄지만, APN은 안드로이드 공통 설정입니다.

One UI나 통신사 설정이 업데이트되면 어떻게 되나요?

적용이 풀리거나 막힐 수 있습니다. 앱 상단에서 적용 여부를 확인하고, 풀렸다면 다시 적용하면 됩니다. 업데이트로 아예 막혔다면 GitHub 이슈로 알려 주시기 바랍니다.

PC나 Shizuku가 필요한가요?

필요 없습니다. 앱이 폰의 무선 디버깅에 직접 연결합니다. 처음 한 번 알림에 페어링 코드만 입력하면 됩니다.

원래대로 되돌릴 수 있나요?

네. '원래대로 되돌리기'를 누르면 APN 유형과 기본 APN이 처음 상태로 돌아갑니다. 유심이 두 개면 둘 다 복구합니다.

공유데이터 한도를 넘겨 핫스팟을 쓰는 것은 통신사 약관에 어긋날 수 있으며, 회선 이용이 제한될 수 있습니다.
