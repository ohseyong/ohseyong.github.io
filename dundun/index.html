안드로이드 테더링 제한,
앱 하나로 해결

데이터를 다 써서 핫스팟이 막혔을 때 APN을 설정해 주는 무료 오픈소스 앱입니다. PC, 루팅, Shizuku 없이 폰 하나로 끝납니다.

APK 받기 GitHub에서 보기

안드로이드 13 이상 · 갤럭시 등 · 무료 · 오픈소스 · 개인 정보 수집 없음

이럴 때 쓰세요

  • 데이터를 다 쓰니 핫스팟이 막혔을 때속도 제한이 걸린 뒤 노트북이나 태블릿을 핫스팟에 연결할 수 없는 경우
  • 알뜰폰에서 핫스팟이 안 될 때핫스팟은 켜지는데 연결한 기기에서 인터넷이 안 되는 경우
  • 예전 방법이 너무 복잡했을 때DunUnlocker와 Shizuku를 같이 깔고 여러 화면을 오가던 과정을 앱 하나로 줄였습니다

사용 방법

  1. 개발자 옵션 켜기앱의 [휴대전화 정보 열기]를 누르고 소프트웨어 정보에서 빌드번호를 7번 누릅니다.
  2. 무선 디버깅 켜기[무선 디버깅 열기]를 누르고 켭니다. 묻는 창이 뜨면 허용을 누릅니다.
  3. 6자리 코드 입력[코드 입력 시작]을 누르고 '페어링 코드로 기기 페어링'을 띄운 뒤, 위에 뜬 알림에 숫자를 넣습니다.
  4. 적용앱이 지금 쓰는 APN에 dun을 더하고 무선 디버깅을 끕니다. '적용 완료'가 뜨면 핫스팟을 켜면 됩니다.

처음 한 번만 하면 됩니다. 다시 적용하거나 되돌릴 때는 무선 디버깅만 켜고 버튼을 누르면 됩니다.

기능

  • 통신사 자동지금 쓰는 APN을 그대로 복사해 dun만 더합니다. 통신사나 알뜰폰을 고를 필요가 없습니다.
  • 지금 상태 표시실제로 적용돼 있는지 맨 위에 보여 주고, 통신사 설정이 바뀌어 풀리면 알려 줍니다.
  • 원래대로 되돌리기버튼 하나로 APN을 처음 상태로 돌립니다.
  • 자동 업데이트새 버전이 나오면 GitHub에서 받아 설치합니다. 같은 키로 서명된 파일만 설치합니다.
  • 12개 언어한국어, 영어, 일본어, 중국어(간체·번체), 스페인어, 포르투갈어, 프랑스어, 독일어, 러시아어, 베트남어, 인도네시아어

안전

  • 소스를 전부 공개합니다모든 코드가 GitHub에 있습니다. 누구나 읽어 보고 직접 빌드할 수 있습니다.
  • 개인 정보를 모으지 않습니다서버도 광고도 분석 도구도 없습니다. 앱이 인터넷으로 접속하는 곳은 새 버전 확인용 GitHub 하나뿐입니다.
  • 하는 일은 APN 설정 하나입니다무선 디버깅 연결은 지금 쓰는 APN에 dun을 더하는 데만 쓰고, 끝나면 무선 디버깅을 바로 끕니다. 루팅도 필요 없습니다.
  • 언제든 되돌릴 수 있습니다'원래대로 되돌리기'를 누르면 APN 타입과 기본 APN이 처음 상태로 돌아갑니다.
  • 서명을 확인하고 설치합니다모든 버전은 같은 키로 서명합니다. 자동 업데이트도 이 키로 서명된 파일만 설치합니다. 서명 인증서 SHA-256: 4B:4B:E3:6B:A7:5E:D7:EA:5D:86:2D:23:8D:FC:C0:7A:10:0E:57:5C:19:49:75:05:D1:12:55:F9:17:F0:C1:66

요청하는 권한

  • 인터넷GitHub에서 새 버전 확인·받기, 폰 안의 무선 디버깅에 연결
  • 네트워크·Wi‑Fi 상태 보기Wi‑Fi에 연결됐는지, 지금 적용돼 있는지 확인
  • Wi‑Fi 멀티캐스트폰 안에서 무선 디버깅 주소 찾기
  • 알림·전체 화면 알림페어링 코드를 넣는 알림을 위쪽에 띄워 두기
  • 포그라운드 서비스코드를 넣고 적용하는 동안 앱이 꺼지지 않게
  • 앱 설치 요청GitHub에서 받은 새 버전 설치
  • 절전 해제·부팅 완료하루 한 번 업데이트 확인 예약

연락처, 위치, 사진·파일, 전화, 카메라, 마이크 권한은 요청하지 않습니다.

무선 디버깅은 켜져 있는 동안 폰에 강한 권한을 여는 기능입니다. 던던은 일이 끝나면 자동으로 끄지만, 직접 켰다면 쓰고 나서 꺼 두세요. 무선 디버깅 설정의 '페어링된 기기'에 DunDun이 남는데, 다시 적용하거나 되돌릴 일이 없으면 지워도 됩니다.

자주 묻는 질문

핫스팟을 써도 테더링(공유) 데이터가 줄지 않나요?

그럴 가능성이 큽니다. 핫스팟 트래픽이 테더링 전용 APN 대신 일반 데이터와 같은 APN으로 나가기 때문입니다. 다만 통신사가 다른 방법으로 테더링을 가려내면 공유 데이터로 잡히거나 막힐 수 있고, 공유 데이터 대신 일반 데이터를 쓰는 것이라 공짜가 되는 건 아닙니다. 처음엔 조금 써 본 뒤 통신사 앱에서 사용량을 확인해 보세요.

어떤 폰에서 되나요? 갤럭시만 되나요?

안드로이드 13 이상 폰이면 됩니다. 갤럭시(One UI 7 이상)에서 많이 겪는 문제라 갤럭시를 먼저 생각하고 만들었고, 기능은 안드로이드 표준이라 다른 제조사 폰에서도 같은 방식으로 동작합니다. 설정 중에 Wi‑Fi 연결이 필요하며, 인터넷이 안 되는 Wi‑Fi도 됩니다.

원래대로 되돌릴 수 있나요?

네. 앱의 '원래대로 되돌리기'를 누르면 APN 타입과 기본 APN을 처음 상태로 돌려놓습니다.

PC나 Shizuku가 필요한가요?

아니요. 앱이 폰의 무선 디버깅에 직접 연결합니다. 처음 한 번 알림에 6자리 페어링 코드를 넣으면 됩니다.

안전한가요?

네. 소스가 GitHub에 모두 공개돼 있고, 서버·광고·분석 도구가 없어 개인 정보를 모으지 않습니다. 앱이 하는 일은 APN에 dun을 더하는 것 하나이고, 끝나면 무선 디버깅을 바로 끕니다. 자세한 내용은 이 페이지의 '안전' 항목에 있습니다.

통신사 약관에 따라 테더링 제한을 우회하면 회선 이용이 제한될 수 있습니다. 쓰는 사람이 판단해 주세요.
