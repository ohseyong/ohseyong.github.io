공유데이터 제한 해제,
앱 하나로

데이터는 남았는데 공유데이터를 다 써서 노트북이 핫스팟에 안 붙을 때 쓰는 앱이에요. APN에 dun을 넣어서 핫스팟이 일반 데이터로 나가게 해요. PC에 연결하거나 루팅할 필요 없이 폰에서 다 끝나요.

데이터가 늘어나지는 않아요. 핫스팟도 일반 데이터에서 빠지고, 일반 데이터를 다 쓰면 요금제에 적힌 속도로 느려져요.

APK 받기 GitHub에서 보기

안드로이드 13 이상에서 돼요. 무료이고 소스도 공개돼 있어요.

이럴 때 써요

  • 데이터 무제한 요금제인데 노트북을 핫스팟에 붙이면 테더링 한도에 걸릴 때
  • T월드 같은 통신사 앱에 공유데이터가 소진됐다고 나올 때
  • 알뜰폰에서 핫스팟은 켜지는데 붙인 기기에서 인터넷이 안 될 때
  • 데이터를 다 써서 느려졌는데, 그 속도로라도 핫스팟을 쓰고 싶을 때

쓰는 법

에뮬레이터(순정 안드로이드 15)에서 찍은 화면이에요. 갤럭시는 메뉴 모양이 조금 다르지만 순서는 같아요. 파란 상자가 누를 곳이에요.

1개발자 옵션 켜기

2무선 디버깅 켜기

3코드 넣기

4끝

처음 한 번만 하면 돼요. 나중에 다시 적용하거나 되돌릴 때는 무선 디버깅만 켜고 버튼을 누르면 돼요. 코드를 다시 넣을 필요는 없어요.

유심이 두 개라면

유심 두 개 모두에 dun을 넣고, 둘 다 그 APN을 기본으로 골라 둬요. 데이터 유심을 바꿔도 다시 할 필요가 없어요. 되돌리기도 유심마다 따로 해서 다른 유심 설정은 건드리지 않아요.

바뀐 APN 확인하기

설정 → 연결 → 모바일 네트워크 → 액세스 포인트 이름에서 선택돼 있는 APN이 DunDun이 바꾼 거예요. 눌러 보면 APN 유형 끝에 dun이 붙어 있어요.

폰에 따라 원래 APN에 dun만 붙기도 하고, 이름이 같은 APN이 하나 더 생기기도 해요. 둘이 헷갈리면 유형에 dun이 있는 쪽을 보면 돼요. 통신사가 넣어 둔 Tethering 같은 APN이 따로 보여도 DunDun은 그건 건드리지 않아요. 앱의 적용 완료 화면에도 유심마다 바뀐 APN 이름과 유형이 나와요.

그 밖에

  • 앱 맨 위에 지금 적용돼 있는지 나와요. 통신사 설정이 바뀌어서 풀리면 바로 보여요.
  • 새 버전이 나오면 GitHub에서 받아서 알아서 설치해요. 처음 한 번만 설치를 허용하면 그다음부터는 묻지 않아요.
  • 한국어, 영어, 일본어, 중국어, 스페인어 등 12개 언어로 나와요.

안전

  • 소스는 전부 GitHub에 있어요. 직접 읽어 보고 빌드해서 써도 돼요.
  • 따로 돌리는 서버가 없고, 광고나 분석 도구도 넣지 않았어요. 앱이 인터넷에 붙는 건 GitHub에서 새 버전을 확인할 때뿐이에요.
  • 무선 디버깅은 APN을 바꾸는 데만 쓰고 끝나면 앱이 바로 꺼요. 무선 디버깅이 켜져 있으면 은행이나 공공기관 앱이 안 열리기도 하는데, 따로 끄러 갈 필요가 없어요.
  • 다 하고 나서 개발자 옵션을 꺼도 바꾼 APN은 그대로 남아요.
  • '원래대로 되돌리기'를 누르면 처음 상태로 돌아가요.
  • 업데이트는 같은 키로 서명된 파일만 설치해요. 서명 인증서 SHA-256: 4B:4B:E3:6B:A7:5E:D7:EA:5D:86:2D:23:8D:FC:C0:7A:10:0E:57:5C:19:49:75:05:D1:12:55:F9:17:F0:C1:66

요청하는 권한

  • 인터넷GitHub에서 새 버전 확인하고 받기, 폰 안의 무선 디버깅에 연결하기
  • 네트워크와 와이파이 상태와이파이에 붙어 있는지, 지금 적용돼 있는지 확인하기
  • 와이파이 멀티캐스트폰 안에서 무선 디버깅 주소 찾기
  • 알림, 전체 화면 알림페어링 코드 넣는 알림을 화면 위에 계속 띄워 두기
  • 포그라운드 서비스코드를 넣고 적용하는 동안 앱이 꺼지지 않게 하기
  • 앱 설치GitHub에서 받은 새 버전 설치하기. 처음 한 번만 물어봐요
  • 절전 해제, 부팅 완료하루 한 번 새 버전 확인 예약하기

연락처, 위치, 사진이나 파일, 전화, 카메라, 마이크 권한은 요청하지 않아요. 무선 디버깅 설정의 '페어링된 기기'에 DunDun이 남는데, 다시 적용하거나 되돌릴 일이 없으면 지워도 돼요.

자주 묻는 질문

테더링을 무제한으로 쓸 수 있게 되나요?

아니요. 핫스팟이 공유데이터 대신 일반 데이터를 써요. 일반 데이터를 다 쓰면 요금제에 정해진 속도로 느려지고, 핫스팟도 그 속도로 써야 해요.

공유데이터는 이제 안 줄어드나요?

보통은 안 줄어요. 통신사는 대개 APN을 보고 핫스팟을 구분하는데, 이제 핫스팟도 일반 데이터와 같은 APN으로 나가거든요. 통신사가 다른 방법으로 구분하면 그대로 잡히거나 막힐 수도 있어요. 처음엔 조금 써 보고 통신사 앱에서 어느 쪽이 줄었는지 확인해 보세요.

NetShare랑 뭐가 달라요?

NetShare는 프록시로 인터넷을 나눠 줘서 노트북에 프록시를 잡아야 하고, 카톡 PC처럼 로그인이 안 되는 프로그램도 있어요. DunDun은 폰의 APN만 바꾸고 핫스팟은 원래 쓰던 대로 써요. 노트북에서 손댈 건 없어요.

갤럭시에서만 되나요?

안드로이드 13 이상이면 돼요. 갤럭시 One UI 7 이상에서 이 문제를 겪는 분이 많아서 갤럭시로 먼저 맞춰 봤어요. APN은 안드로이드 공통 설정이라 다른 폰에서도 같은 방법으로 바꿔요.

One UI나 통신사 설정이 업데이트되면요?

풀리거나 막힐 수 있어요. 앱 맨 위에 지금 적용돼 있는지 나오니까, 풀렸으면 다시 적용하면 돼요. 업데이트로 아예 막히면 GitHub 이슈로 알려 주세요.

PC나 Shizuku가 필요한가요?

필요 없어요. 앱이 폰의 무선 디버깅에 직접 붙어요. 처음 한 번 알림에 페어링 코드만 넣으면 돼요.

원래대로 되돌릴 수 있나요?

네. '원래대로 되돌리기'를 누르면 APN 유형과 기본 APN이 처음 상태로 돌아가요. 유심이 두 개면 둘 다 돌려요.

공유데이터 한도를 넘겨서 핫스팟을 쓰는 건 통신사 약관에 어긋날 수 있어요. 회선 이용이 제한될 수도 있으니 알고 쓰세요.
